# 全球标杆设计与组件参考站「最小个体」调研汇总

- **调研日期**：2026-11-27
- **调研范围**：5 大类共 18 个代表性平台（Mobbin · Refero · Page Flows · Godly · Lapa Ninja · Land-book · Curated Design · getdesign.md · tweakcn · UI UX Pro Max · Design Systems Surf · 21st.dev · Aceternity UI · Magic UI · Origin UI · Shadcnblocks · Tailwind Plus · Vercel Templates · Framer Marketplace · Cruip）

---

## 1. 产品界面与流程库（Mobbin · Refero · Page Flows）

- **Mobbin (`mobbin.com`)**：
  - **多端切换**：同一产品下切 `iOS / Android / Web`，并保留历史版本时间轴（看产品改版演进）。
  - **四维标签页**：`Screens`（按页面类型分类的全部真实截图，支持搜图内文字）、`Flows`（连续操作流程树，如注册、结账、付费墙，支持点击热区像真原型一样跳转）、`UI Elements`（从整页里切出来的局部小部件，如弹窗、导航栏、选择器）、`Marketing Pages`（专门把宣传官网与登录后的软件内页拆开）。
  - **短板**：只有像素图，缺颜色变量名、缺悬停/报错/加载状态、缺动效时长曲线、缺手机折叠规则，AI 看图只能瞎猜硬编码。
- **Refero (`refero.design`)**：
  - 按 `Page Types`（落地页、定价、404、空状态、设置）、`UX Patterns & Flows`、`UI Elements` 拆解。
  - **独家亮点（Refero Styles）**：除了真实页面截图，直接提取该产品的色板 Hex、字族字号字重、圆角间距，并支持导出 `DESIGN.md` 或经 MCP 喂给 AI。
- **Page Flows (`pageflows.com`，已整合 Screenlane)**：
  - **独家亮点**：带步骤批注的**真实操作录屏视频**（能看清点击、加载、报错、转场节奏），外加 `Emails`（欢迎邮件、账单通知邮件）。

## 2. AI 设计协议与风格主题站（getdesign.md · tweakcn · UI UX Pro Max · Design Systems Surf）

- **getdesign.md**：
  - 9 大标准章节：视觉氛围意图（为什么这么设计）· 色板与语义分工 · 字体排印规则 · 核心组件配方（四态）· 布局留白原则 · 深度与层级 · 正反规范（Do / Don't 防 AI 味禁令）· 响应式折叠规则 · AI 速查提示块。
  - 配套 `preview.html / preview-dark.html` 样板页与 `npx getdesign add <slug>` 一键写入项目根目录 `DESIGN.md`。
  - **短板**：预览页只有基础色卡和孤立按钮，缺真实多页面上下文，且参数不可在线微调。
- **tweakcn (`tweakcn.com`)**：
  - **独家亮点 1**：同一套风格实时套壳到 **多套真实业务样板页（数据后台 Dashboard · 卡片墙 Cards · 邮件客户端 Mail · 定价页 Pricing · 登录表单 Auth）**，一眼看清风格进真实业务长啥样。
  - **独家亮点 2**：内置文字对比度达标检查 + 插入一行脚本即可在开发者自己的 `localhost` 本地项目里实时预览换肤效果。
  - **短板**：只有冰冷色值变量，没有布局规矩与 AI 禁令，单丢变量给 AI 照样写出平庸排版。
- **UI UX Pro Max**：
  - 单套风格结构化记录：`适用场景 Best For`、`禁用场景 Do Not Use For`、动效关键词、性能/无障碍/移动端友好度评级、落地检查清单，并支持生成全局 `MASTER.md` + 单页覆盖规范。
- **Design Systems Surf (`designsystems.surf`)**：
  - 按 `基础变量 Tokens + 组件解剖 Components（结构 + 状态）+ 规范文档 Guidelines` 三维拆解真实大厂设计系统。

## 3. 现代组件与交互动效市场（21st.dev · Magic UI · Aceternity · Origin UI · Shadcnblocks）

- **21st.dev**：
  - **招牌能力「Copy AI Prompt」**：把源码包进给 AI 的施工单——含前置环境检查、完整源码、自动装依赖包清单、图片/图标兜底规则、以及要求对齐项目现有颜色变量（禁止写死孤岛色值）。（注：原版末尾塞了一堆让 AI 反问用户的问卷，属于画蛇添足，应砍掉反问直接出活）。
  - 配套：实时交互沙盒 + 桌面/平板/手机视口 + 深浅色切换 + 多变体示例（Demos） + 多文件源码树 + 一行命令安装。
- **Magic UI & Aceternity UI**：
  - 动效预览框右上角必配 **重播按钮（Refresh）**；安装区明确列出所需外部包与关键帧动画配置（Tailwind v4 `@theme`）；底部配极简四列参数表（属性名 · 类型 · 默认值 · 说明）。
  - **避坑教训**：重粒子/全屏光效在手机和苹果浏览器极易掉帧卡死；暗黑霓虹「孤岛配色」贴进普通项目极突兀，组件必须吃全局语义颜色变量。
- **Origin UI (`coss.com/ui`) & Shadcnblocks**：
  - 同品类下平铺展示多种实用变体，顶部支持直接切换多套主题皮肤看同一组件在不同风格下的表现。

## 4. 整站与单页模板平台（Tailwind Plus · Vercel · Framer · Cruip）

- **全页面缩略图矩阵（All Pages Included）+ 真机多端沙盒**：一眼摊开包含的所有子页面（首页、定价、内页、登录、404），绝不只拿一张斜角样机图糊弄，且支持在独立沙盒里真实点击跳转切电脑/平板/手机。
- **硬核技术与依赖清单（Vercel / Tailwind Plus）**：直白标清框架、样式方案、图标/字体依赖（明确标出是否全部免费商用字体）、目录结构，不写「极致性能、颠覆美学」这类营销废话。
- **包含的积木与全局规范拆解**：标明该模板用了哪套设计风格、拆出了哪些可复用区块，支持一键命令行拉取、下载干净源码包或复制复刻指令给 AI。

## 5. 顶级网站灵感与落地页拆解站（Godly · Lapa Ninja · SaaS Landing Page · Land-book · Curated Design）

- **Godly (`godly.website` / `recent.design`)**：
  - **独家亮点**：默认循环播放**真实滚动与交互录屏视频**（不用点开原站就能看清悬停、转场和滚动动效），配桌面端 / 手机端双视图切换、使用的字体名与建站技术栈标签。
  - **短板**：偏重艺术炫技难落地，缺乏按内部区块（如定价表）的切分。
- **SaaS Landing Page (`saaslandingpage.com`) & Lapa Ninja (`lapa.ninja`)**：
  - **独家亮点**：同一个品牌按**真实页面角色拆多页**（首页 Home · 定价 Pricing · 功能 Features · 登录 Login · 更新日志 Changelog · 关于 About），提供整页一镜到底高清长图（支持下载长图）、主色板 Hex 与字体名、上下翻页（`← Prev / Next →`）与相似风格推荐。
- **Land-book (`land-book.com`) & Curated Design (`curated.design`)**：
  - **独家亮点**：极细的**版式特征标签**（如 `显式细边框 Visible Borders`、`超大标题 Big Type`、`大页脚 Big Footer`、`双栏首屏`），以及精准对应现代前端技术栈（如 Next.js + Tailwind + Geist 字体）。
  - **共同短板（为什么 AI 看图抄不准）**：① 6000px 长图直接喂给 AI 会丢细节，缺「从上到下的区块骨架拆解树」；② 商业收费字体（如 PP Neue Montreal）AI 用不了，缺「免费开源平替字体映射」；③ 只有静态正常态，缺悬停/点击/报错多态说明。

## 6. 风格与主题友商补充深挖（Happy Hues · Realtime Colors · shadcn Themes & Create）

- **Happy Hues (`happyhues.co`)**：
  - **独家贴心细节（色块部位映射 `This section's hues`）**：绝不只摆一排冷冰冰的色块，明确标出每一个色号具体涂在界面哪个零件上（画布底色 · 卡片底色 · 大标题 · 正文 · 卡片正文 · 主按钮底 · 按钮文字 · 描边线条），解决「拿了色号不知道怎么配比」的痛点。
- **Realtime Colors (`realtimecolors.com`)**：
  - **独家贴心细节**：① 同一套风格一键切 **宣传页（Landing）/ 数据后台（Dashboard）/ 长文博客（Typography）** 验证密集与留白表现；② 自动计算核心文字与底色、按钮字与主色的对比度，挂出 **红/黄/绿灯可读性徽章（如 `12.4:1 AAA`）**。
- **shadcn Themes & Create (`ui.shadcn.com/themes` & `/create`)**：
  - 轻量胶囊调参条（圆角档位 · 间距密度 · 明暗切换）+ 顶部一键复制 `:root` 与 `.dark` 双套 CSS 变量 + Tailwind v4 `@theme`。

## 7. 整站与单页模板详情页补充深挖（Cruip · Shadcnblocks · Framer · Tailwind Plus）

- **Cruip (`preview.cruip.com`) & Shadcnblocks Templates (`shadcnblocks.com/templates`)**：
  - **独家贴心细节 1（预览窗顶部常驻路由与设备条）**：不用新开十几个标签页，预览框顶栏直接放 **子页面路由切换器（`Home / Pricing / Docs / Changelog / Login`）+ 视口切换（电脑 / 平板 / 手机）+ 明暗切换**，且切换子页时保持当前选中的手机宽度和明暗模式不重置！
  - **独家贴心细节 2（子页缩略图矩阵联动）**：下方平铺展示全套包含的子页面（带用途一句话说明，如 `Pricing - 含月付年付切换与常见问题`），点哪张直接把上方预览沙盒切到哪一页。
  - **独家贴心细节 3（积木化拆解）**：列出整站模板由哪几个区块积木（首屏、便当格、定价、页脚）拼成，既能一键拎走整站，也能点进某块积木单独拷走。

## 8. 组件详情页补充深挖（21st.dev · Motion Primitives · Coss/Origin UI · Magic UI · Shadcnblocks）

- **黄金首屏结构**：极简抬头 → 占首屏 65%+ 权重的实时交互舞台（顶置工具栏）→ 三轨交付区（复制 AI 施工指令 / CLI / 分文件源码）→ 状态变体流 → 底部 4 列 Props 参数表。
- **21st.dev 双向回写与 6 合 1 施工指令**：右侧调参滑块（圆角、紧凑度、皮肤）改动后，实时回写进源码和 `Copy AI Prompt`；AI 提示词固定打包「主题变量对齐 + 第三方包清单 + CSS 关键帧 + 纯组件与 Demo 分文件源码 + 客户端/无障碍标记 + 最小调用示例」，砍掉啰嗦反问。
- **Magic UI / Motion Primitives / Coss UI 防踩坑细节**：① 组件本体（`Component.tsx`）与假数据演示（`Demo.tsx`）必须分文件，避免用户拷走一堆假数据；② 显式单列外部依赖包与自定义动画配置，杜绝红屏报错；③ 舞台支持切画布底纹（纯色/点阵）与状态变体（默认/紧凑/加载）。
