# 组件库与三栏实时工作台

- **模块定位**：承载渐进式组件与动效资产库的三级浏览与调参闭环——一级分类总览、二级单分类画廊、三级「左树 + 中舞台 + 右调参与目录」实时工作台及隔离预览画布。
- **对应代码**：`src/features/library/`、`src/app/[locale]/(site)/components/`、`src/app/[locale]/(canvas)/preview/`
- **所属里程碑**：[M4](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：
  1. 一级总览（`/components`）：按 Section / Block / Page / Motion 四类筛选、关键词搜索、排序（热门 / 数量 / 字母）与 4 列 / 3 列 / 列表视图切换；
  2. 二级分类页（`/components/[category]`）：子分类标签过滤、2 列 / 3 列切换与 16:10 微缩动态令牌标本画廊；
  3. 三级实时工作台（`/components/[category]/[slug]`）：左侧虚拟源码文件列表与全库组件快捷切换树、中央桌面/平板/手机多视口预览舞台与 React/Vue/Svelte/Solid 四框架 Shiki 语法高亮源码切换、右侧圆角/密度/品牌皮肤实时调参器与本页锚点目录；
  4. 独立画布（`/preview/components/[category]/[slug]`）：供真实视口宽度响应式预览使用的纯净页面路由。
- **不负责**：底层令牌换算公式与多框架模板字符串拼装（委托 `src/core/` 完成）。

## 2. 结构与数据流
- 工作台同时读取 URL 参数（`fw`、`tab`、`vp`、`file`）与全局 `workbench-preset` Store（`radius`、`density`、`skin`、`stageMode`）。
- 参数变更时实时经过 `core/tokens` 计算令牌对象，一方面直接驱动预览标本样式与数字计数重播，另一方面经 `core/codegen` 刷新当前选中框架源码与安装 CLI 命令。

## 3. 关键决策
- 工作台拆分为 `toolbar/`、`tree-sidebar/`、`stage-panel/`、`params-panel/` 四个独立子目录，避免单组件文件堆砌。
- 同时提供内嵌容器即时预览与 `/preview/...` 同源独立画布路由，为后续填入复杂响应式真实组件预留完整视口隔离能力。

## 4. 当前实现
- 已完成 `features/library/{overview,category,workbench}/` 三级组件库目录与 `workbench/{toolbar,tree-sidebar,stage-panel,params-panel}/` 四分拆子模块，并打通 `/preview/components/[category]/[slug]` 与 `/preview/templates/[slug]` 独立隔离预览画布路由。

## 5. 验证方式
- 验证从一级分类 → 二级画廊 → 三级工作台的完整跳转；在工作台切换圆角（`0px ~ 16px`）、密度、品牌皮肤、视口尺寸与四大前端框架代码标签，确认舞台外观与高亮代码同步更新。

## 6. 待扩展项
- 支持一键将当前组件的多个虚拟文件（组件代码 + `tokens.css` + `DESIGN.md`）打包为 `.zip` 下载。
