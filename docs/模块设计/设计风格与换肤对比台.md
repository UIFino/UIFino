# 设计风格与换肤对比台

- **模块定位**：提炼 10 套通用 UI 设计流派的明暗色板、圆角档位、边框阴影特征与设计护栏，提供纯净平铺流派卡片墙、流派 `DESIGN.md` 详情页（左侧流派树支持保持 URL 样板与明暗参数 0 秒换肤切换），并与组件预览皮肤系统无缝互通。
- **对应代码**：`src/core/styles/`、`src/registry/styles/`、`src/features/styles/`、`src/app/[locale]/(site)/styles/`、`src/i18n/messages/{zh,en}/styles.json`
- **所属里程碑**：[M6](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-28

## 1. 职责与边界
- **负责**：
  1. 维护现代克制系（细线网格、极简黑白、瑞士排版、清爽商务、杂志衬线）与质感先锋系（毛玻璃、便当格、新粗野、微浮雕、复古终端）共 10 套流派资产；
  2. `/styles` 频道页：提供纯净平铺流派卡片墙，支持按深浅色系、四大适用场景、关键词与全局暗亮模式预览过滤；
  3. `/styles/[slug]` 详情页：展示实时样板预览（数据后台 / 宣传首屏 / 卡片与认证 / 排版与字阶）、深浅色板对照、表面特征与实现护栏、Shiki 高亮 `DESIGN.md` 查看/复制/下载，以及一键套用至组件预览工作台；左侧流派树切换通过 `?tpl=...&mode=...&tab=...` 保留当前样板状态，实现详情页内 0 秒同样板换肤对比。
- **不负责**：具体行业品牌的专属规范拆解（归属 `catalog` 频道）。

## 2. 结构与数据流
- `src/core/styles/` 提供纯函数协议编译器 `compileStyleDesignMd` 与表面物理参数换算器 `resolveStylePlaygroundPhysics`，无 React 依赖并配独立 Vitest 单元测试。
- `UiStyleSpec` 直接兼容 `BrandSkinContract` 契约，经 `src/registry/skins.ts` 汇总注入组件工作台，实现品牌皮肤与流派皮肤统一换肤。
- 列表筛选通过 `nuqs` 同步至 URL（`?tone=...&scenario=...&mode=...`）；详情页左栏流派切换透传 `?tpl=...&mode=...&tab=...`，保证切换流派时不重置当前选中的样板视图。

## 3. 关键决策
- 顶部下拉抽屉与侧栏流派列表统一挂载 `10×10px` 双色微色块（`DualSwatch`：左半画布底色 + 右半强调色），零文字噪音即可一眼辨识流派色温。
- 砍掉列表页冗余的独立「换肤对比（`?view=compare`）」视图，将列表聚焦为风格卡片墙，把同样板实时换肤体验集中收口在 `/styles/[slug]` 详情页左侧流派树中。

## 4. 当前实现
- 已完成 `core/styles/`（含单测）、`registry/styles/` 下 10 个独立流派子目录、`features/styles/{specimens,styles-list,style-detail}/` 与 `/[locale]/styles` 静态路由生成。

## 5. 验证方式
- 运行 `pnpm test` 校验协议编译与物理参数计算；在浏览器访问 `/zh/styles` 验证筛选与卡片墙展示，进入 `/zh/styles/hairline-grid?tpl=landing` 切换左侧流派验证样板保持与圆角/表面特征实时更新。

## 6. 待扩展项
- 后续随友商调研继续在 `src/registry/styles/<slug>/` 横向扩充更多细分视觉流派。
