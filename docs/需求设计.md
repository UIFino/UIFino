# 需求设计

- **状态**：讨论中
- **最近更新**：2026-11-27

## 1. 一句话定位

做一个**集百家所长的前端设计与现成资产百宝箱**（UIFino）：既有人能逛的现成标杆产品参考、通用视觉风格参考、组件库、整站模板和常见前端设计工具，又能一键接入用户的 AI 编程工具，让 AI 直接照着这个百宝箱抄出高质感界面。现阶段专注把产品和内容做好，暂不考虑付费变现。

## 2. 背景与痛点

- **人找参考难落地**：平时看到好看的网站或手机应用，只能截图看个大概，拿不到准确的色号、字号、圆角和间距规律。
- **AI 写界面像廉价模板**：直接让 AI 写网页，出来的配色刺眼、间距松散、满屏套路感，缺少真实成熟产品的克制质感。

## 3. 谁在用

| 角色 | 怎么用 | 要什么 |
| :--- | :--- | :--- |
| **人类使用者**（程序员、独立开发者、产品经理） | 逛网站挑顺眼的风格、组件和整站模板，在线调参数看效果，复制规范或源码 | 审美在线、分类清楚、拿来就能改、不用自己从零配颜色和排版 |
| **AI 编程工具**（如 Claude Code、Cursor 等写代码软件） | 通过接口、命令行或读取复制过去的设计说明书，按规则生成页面代码 | 结构清楚、数值明确、带硬性设计护栏（写明什么能做、什么禁止做）的说明与代码模板 |

## 4. 名词解释

| 名词 | 大白话解释 |
| :--- | :--- |
| `DESIGN.md` | 给 AI 和人看的结构化品牌设计说明书，写清一套界面的配色、字体、圆角、间距和排版禁忌 |
| `MCP` | 让 AI 编程软件直接连上网站查设计说明书、拉组件源码的通用接口协议 |

## 5. 需求点（随讨论逐步补齐）

- **阶段边界**
  - 首阶段完全免费开放，不做付费墙、会员订阅与收款流程，免登录即可顺畅使用核心功能。
- **最小个体内容规格（逐步定稿中）**
  - **① 单套「设计图鉴」个体**：
    - 抬头区：名称、原站直链、平台与短标签、`✓ 适合用来做什么`、`✕ 别拿来做什么`；右侧动作含 **复制 CSS（含明暗 CSS 变量与 Tailwind v4 配置）**、复制 `DESIGN.md`、下载 `.md`、套用此皮肤逛组件库（砍掉一切虚构安装/收藏数字）。
    - 内容四标签：① **公开多页长图 + 交互式设计原语目录**（自动抓取首页/定价/更新日志/登录等免登录页的电脑+手机截图，采集时同步记录每一屏区块占全图的精确百分比坐标范围；点击右侧任意一条「前端设计原语」，左侧长图自动平滑滚到对应位置并用醒目红框+聚光遮罩标定范围，点击左侧图片也可反向高亮右侧原语，单条原语支持独立复制）；② **自动区块切片**（按网页区块坐标自动裁出顶栏/首屏/定价/页脚切片图）；③ **真实样式数值与 CSS**（浏览器读取真实色号占比、原站字体+免费平替字体、字号圆角阴影容器宽度、按钮/卡片悬停前后色差，支持单点或整份复制 CSS）；④ **正反护栏与 `DESIGN.md`**（`✓ 必守特征` + `✕ 防 AI 味禁令` + 协议全文）。
  - **② 单套「风格」个体（融合 Happy Hues + Realtime Colors + shadcn Create + tweakcn）**：
    - 抬头标明 `✓ 最适合场景` 与 `✕ 禁用场景`，顶部动作一排收紧为 **复制 CSS 变量（`:root`+`.dark`+Tailwind v4）**、复制 `DESIGN.md`、下载 `.md`、套进组件库。
    - 主舞台支持切换 **4 套高差异真实页面样板（数据后台 · 宣传首屏 · 卡片与登录表单 · 长文排版与字阶）**，支持深浅色切换与现场圆角/紧凑度微调。
    - **色块部位映射 + 自动对比度体检**：每个色号明确标注涂在页面哪个具体部位（画布底 / 卡片底 / 大标题 / 正文 / 按钮底 / 按钮字 / 描边），并自动计算配对可读性挂出 `AAA / AA` 对比度绿灯徽章；底部展示核心 CSS 公式与代表真站图鉴关联。
  - **③ 单个「组件」个体（融合 21st.dev + Motion Primitives + Coss/Origin UI + Magic UI + Shadcnblocks）**：
    - 抬头精简并标注适用位置，主动作配备 **复制 AI 施工指令**（6 合 1 自包含图纸：对齐项目变量、依赖清单、动画配置、纯组件与演示分文件源码、客户端/无障碍约束、调用示例；右侧调参结果实时回写进源码与指令）+ 复制源码 + 支持包管理器切换的 CLI 命令。
    - 活体舞台支持电脑/平板/手机宽度、深浅色、画布底纹（纯色/点阵）、动效重播、换皮肤，以及 **多状态变体切换（默认态 · 紧凑态 · 空/加载态）**。
    - 源码区严格拆分 `Component.tsx`（纯组件）与 `Demo.tsx`（示例数据）及 `tokens.css`，单列外部依赖防漏装提示，底部配标准 4 列属性参数表（属性名 · 类型 · 默认值 · 说明）。
  - **④ 单套「模板」个体（融合 Cruip + Shadcnblocks + Framer + Tailwind Plus + Vercel）**：
    - 拒绝静态斜角 3D 样机图与吹牛营销词；抬头标明包含页数与 `✓ 适合用来做` / `✕ 别拿来做`，右侧提供 **新窗口真机试玩**、**复制整站 AI 复刻指令**、**复制 CSS** 与 **命令行初始化**。
    - 内嵌多端可点击沙盒顶部常驻 **子页面路由切换条（首页 / 定价 / 文档 / 日志 / 登录等）+ 电脑/平板/手机宽度 + 深浅色切换**，切换子页面时自动保持当前设备宽度与明暗状态。
    - 下方依次展示：① **全部子页面缩略图矩阵**（带路由与包含内容说明，点击直接切上方沙盒）；② **组成积木拆解**（列出用到的组件积木，点击直达组件库单独拷走）；③ **全局配色字体提纯与零黑盒技术目录树**。
- **顶部菜单六大一级板块（已确认）**
  - **1. 设计图鉴（`Catalog`）**：拆解真实标杆网站与手机应用；子菜单按「探索（全部图鉴 · 桌面网站 · 移动应用）+ 领域（人工智能 · 开发工具 · 效率办公 · 金融支付 · 内容社区 · 生活出行）+ 网站精选 + 应用精选」组织。
  - **2. 风格（`Styles`）**：通用设计流派平铺 + 同界面实时换肤对比；子菜单按「探索（全部风格 · 换肤对比 · 深色系 · 浅色系）+ 现代克制 5 流派 + 质感先锋 5 流派 + 适用场景（宣传官网 · 数据后台 · 智能工作台 · 文档阅读）」组织。
  - **3. 组件库（`Components`）**：只放局部积木，不做多框架切换，只输出一套干净标准代码加设计说明；子菜单按「探索（全部组件 · 官网区块 · 功能模块 · 交互动效）+ 官网区块（7 类）+ 功能模块（9 类）+ 交互动效（5 类）」组织。
  - **4. 模板（`Templates`）**：承接多页整站工程与单页模板；子菜单按「探索（全部模板 · 整站工程 · 单页模板）+ 整站场景（6 类）+ 单页模板（6 类）+ 精选成品」组织。
  - **5. 工具（`Tools`）**：前端常见视觉参数工具；子菜单按「探索（全部工具 · 背景纹理 · 多层阴影 · 配色对比 · 字号排版）+ 背景预设 + 阴影预设 + 实用换算」组织。
  - **6. 接入到 AI（`Connect AI`）**：连接全站百宝箱；子菜单按「探索（快速接入 · 检索沙盒 · 命令行 · 提示词库）+ 百宝箱能力 + 导出格式 + 支持软件」组织。
  - **分类演进说明**：上述六大板块的子分类属于首轮骨架，后续将结合友商深度调研横向扩充更多细分类型与资产内容。
  - **顶栏右侧常驻工具**：全局搜索、全局预览预设、中英文切换、明暗主题切换（去掉无实际用途的假点赞数；悬停子菜单展开期间顶栏只亮当前悬停项单条底线）。

## 6. 非功能与体验要求

- 支持中文、英文双语切换，支持深色、浅色双主题预览。
- **导航与分类短词铁律**：全站下拉菜单与分类标签一律用极简短词——中文控制在 **2～4 个字**（严禁写成「XX与XX」的啰嗦拼词），英文控制在 **1 个单词（最多 2 个短词）**（严禁满屏 `&` 拼接）。
- **AI 可批量自动化生产铁律**：图鉴等资产的字段设计必须保证能由 AI 代理（无头浏览器脚本 + 视觉模型）从公开网页自动批量抓取生成；坚决不做需要人工登录后台、手工录视频、串联复杂交互流或盲猜底层技术栈的重人力内容。
- 面向国内外开发者均可顺畅访问。
