# 前端设计

- **一句话视觉方向**：融合 `getdesign.md` 的暗色建筑感 1px 结构线网格、荧光黄绿高对比丝带，与 `shadcn.io` 的无间隙细线卡片矩阵、悬停滑窗大菜单及三栏实时工作台。
- **参考来源**：
  - `getdesign.md`：借鉴深炭黑画布、通栏 1px 细线边框、45° 斜纹分隔带、顶部齐平荧光黄绿丝带标签与双栏规范详情拆解版式。
  - `shadcn.io`：借鉴通栏纯文字抽屉导航与全屏压暗模糊遮罩（GlobalNav Flyout，左 1 大字主列 `21px` + 右侧紧凑单行细分列 `13.5px`，零简介/零徽章/零箭头）、1px 无间隙网格（Lined Grid）、三层叠放微缩分类卡（Mini Stack）与左树-中舞台-右调参三栏工作台布局。
  - `linear.app` & `vercel.com`：借鉴高对比黑白实心主按钮、等宽数字对齐（`tabular-nums`）与克制中性色面积占比（≥ 90% 中性色，仅焦点处用强调色）。
- **对应代码目录**：`src/styles/`、`src/components/primitives/`、`src/components/patterns/`、`src/components/shell/`
- **当前状态**：已定稿
- **最近更新时间**：2026-11-27

### 1.2 字族与字号阶梯
1. **字族定义**（通过 `next/font/google` 本地化自托管）：
   - 正文字族 `--font-sans`：`"Geist", -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`
   - 等宽数据字族 `--font-mono`：`"Geist Mono", "SFMono-Regular", Consolas, monospace`（全局指标与代码强制开启 `font-variant-numeric: tabular-nums`）
   - 品牌像素字族 `--font-pixel`：`"Silkscreen", "Geist Mono", monospace`（专用于 `uifino` 品牌标识，`letter-spacing: 0.1em`）
   - 人文衬线字族 `--font-serif`：`"Cormorant Garamond", Georgia, serif`（专用于人文衬线风格图鉴与首屏标本）
2. **字号与行高阶梯**：
   - `Hero 标题`：`clamp(28px, 3.2vw, 40px)`，字重 `700`，行高 `1.06`，字距 `-0.028em`
   - `频道横幅标题`：`clamp(28px, 3.2vw, 38px)`，字重 `700`，行高 `1.10`，字距 `-0.03em`
   - `内页主标题`：`clamp(24px, 2.5vw, 32px)`，字重 `600`，行高 `1.14`，字距 `-0.022em`
   - `区块标题`：`20px`，字重 `600`，行高 `1.25`，字距 `-0.015em`
   - `常规正文`：`14px ~ 15px`，字重 `400`，行高 `1.55 ~ 1.62`
   - `紧凑控件 / 代码 / 表格`：`12px ~ 13px`，字重 `500`，行高 `1.5`
   - `等宽眉标（Eyebrow）`：`10.5px`，字重 `600`，大写，字距 `0.10em`

### 1.3 间距、圆角与阴影阶梯
- **基准间距阶梯（4px 模数）**：`4px` · `8px` · `12px` · `16px` · `20px` · `24px` · `28px` · `36px` · `44px`
- **容器尺寸**：顶栏高度 `--header-h: 56px`（通栏全宽贴边），标准主容器 `--container-max: 1380px`；底层侧栏详情页采用「`248px` 左导轨贴边 + 右区居中 `1180px`（`border-x` 细线装框）」，工作台三栏全屏展开且中舞台居中收束至 `1060px` 兼顾宽屏可读性与视觉平衡
- **壳层圆角**：站点外框架（顶栏按钮、分段器、徽章、大菜单、代码框）统一使用 `0px` 直角建筑切面；工作台预览舞台内部支持 `0px` / `4px` / `8px` / `12px` / `16px` 五档动态圆角切换
- **浮层阴影**：
  - 暗色大菜单 / 弹窗：`0 24px 64px rgba(0, 0, 0, 0.56), inset 0 1px 0 rgba(255, 255, 255, 0.05)`
  - 亮色大菜单 / 弹窗：`0 20px 48px rgba(27, 26, 23, 0.14)`

## 2. 布局与响应式断点

1. **断点标准**：
   - 移动端：`< 640px`（单列网格，横幅内边距收窄至 `30px 20px`，指标条由 4 列折为 2×2）
   - 平板端：`640px ~ 1023px`（图鉴与分类网格切为 2 列，三栏工作台折叠为上下堆叠且预览舞台置顶）
   - 桌面端：`1024px ~ 1239px`（分类网格切为 4 列，工作台左树 `248px` + 中舞台自适应）
   - 宽屏桌面：`≥ 1240px`（三栏工作台完整展开：`248px` 左树 + 自适应中央舞台 + `272px` 右侧调参及目录栏；设计图鉴与风格详情页采用 `248px` 左导轨 + 全宽主展示区两栏布局）
2. **无间隙 1px 网格画法（Lined Grid）**：父容器设置 `gap: 1px; background: var(--border-hairline)`，子单元格设置 `background: var(--bg-canvas); min-width: 0`，避免双倍边框重叠与长代码撑破布局。

## 3. 基础组件六态与系统反馈态规范

### 3.1 基础交互组件六态（按钮 / 分段项 / 树节点 / 输入框）
- **默认态（Default）**：`1px solid var(--border-hairline)` 边框，清晰前景对比。
- **悬停态（Hover）**：细线按钮切至 `--gray-100` 背景与 `--border-strong` 边框；平铺导航与树节点叠加 `--surface-hover`，过渡时长 `140ms`。
- **按下/激活态（Active / Pressed）**：分段器选中项使用 `--gray-100` 底色与 `600` 字重；左侧树选中项左侧亮起 `2px solid var(--accent-text)` 指示线。
- **聚焦态（Focus-Visible）**：键盘 Tab 聚焦显示 `2px solid var(--accent-text)` 内轮廓（`outline-offset: -2px`），绝不隐藏焦点环。
- **禁用态（Disabled）**：`opacity: 0.45`，`cursor: not-allowed`，屏蔽点击与悬停变色。
- **加载/错误态（Loading / Error）**：按钮加载时显示等宽旋转指示并锁定重复点击；输入校验错误时边框切为高辨识语义红并关联 `aria-invalid`。

### 3.2 空状态、加载状态与错误状态统一画法
- **空状态（Empty State）**：居中放置细虚线或 1px 细线容器，仅保留简洁结论（「没有匹配的条目」）与直接恢复按钮（「清空筛选条件」），不堆放无意义插画。
- **加载状态（Loading State）**：使用与真实卡片同比例的 `--bg-surface` 骨架块配合低对比脉冲过渡，保持页面高度稳定不跳动。
- **错误状态（Error Boundary / 404）**：沿用站点建筑网格容器，展示明确状态码、简短原因与「返回首页 / 重试」主操作按钮。

## 4. 动效与无障碍底线

1. **动效时长与缓动**：
   - 按钮/边框微交互：`130ms ~ 160ms ease`
   - 通栏导航抽屉与全屏背景遮罩（`backdrop-blur-md`）过渡：`200ms ease`，分类叠卡展开：`220ms cubic-bezier(0.2, 0.8, 0.2, 1)`
   - 数字滚动计数：`680ms` 三次方缓出（`1 - (1 - p)^3`）
   - 通栏导航抽屉移出防抖关闭延迟：`140ms`（顶栏与通栏抽屉零缝隙贴合，杜绝斜向移入误关闭）
2. **无障碍要求**：
   - 所有正文与交互文字对比度 ≥ `4.5:1`（亮色模式专门将荧光绿文字替换为深莓红 `#8C145D` 以达标）；
   - 全局支持 `⌘K / Ctrl+K` 呼出搜索、上下键选条目、`ESC` 关闭任意弹层；
   - 检测 `prefers-reduced-motion: reduce` 时立即跳过数字计数动画与位移动效。
