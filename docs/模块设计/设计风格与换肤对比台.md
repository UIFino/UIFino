# 设计风格与换肤对比台

- **模块定位**：提炼 10 套通用 UI 设计流派的明暗色板、圆角档位、边框阴影特征与设计护栏，提供纯净平铺流派卡片墙、流派 `DESIGN.md` 详情页（左侧流派树支持保持 URL 样板与明暗参数 0 秒换肤切换），并与组件预览皮肤系统无缝互通。
- **对应代码**：`src/core/styles/`、`src/registry/styles/`、`src/features/styles/`、`src/app/[locale]/(site)/styles/`、`src/i18n/messages/{zh,en}/styles.json`
- **所属里程碑**：[M6](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-28

## 1. 职责与边界
- **负责**：
  1. 维护现代克制系（细线网格、极简黑白、瑞士排版、清爽商务、杂志衬线）与质感先锋系（毛玻璃、便当格、新粗野、微浮雕、复古终端）共 10 套流派资产；
  2. `/styles` 频道页：提供纯净平铺流派卡片墙，支持按深浅色系、四大适用场景、关键词与全局暗亮模式过滤；每张卡片按所属流派质感渲染差异化微缩界面骨架与底部 5 色语义色带；
  3. `/styles/[slug]` 详情页：重构为对齐图鉴详情页的三栏工作台——左 `208px` 粘性可搜索/按场景筛选的可折叠流派目录树、顶部 `44px` 控制条（`实时样板 · 色板体检 · 护栏与协议` + 4 套样板切换 + 圆角 `0/4/8/16px` + `Dark/Light` + `←/→` 上下一套快切）、中间 100% 满宽沉浸舞台（支持「数据后台 · 宣传首屏 · 登录表单 · 长文阅读」四套饱满业务骨架，并在左栏切换流派时通过 `?tpl=...&mode=...&r=...&tab=...` 保持状态不重置）与右侧 `340px` 粘性 `StyleRightInspector`（主/次交付按钮、正反适用场景、7 色带+部位标注+防融底内描边+3 组 `AA/AAA` 徽章、物理排版公式与关联真站图鉴）。
- **不负责**：具体行业品牌的专属规范拆解（归属 `catalog` 频道）。

## 2. 结构与数据流
- `src/core/styles/` 提供纯函数协议编译器 `compileStyleDesignMd`、对比度审核 `computeContrastRatio` 与表面物理参数换算器 `resolveStylePlaygroundPhysics`，无 React 依赖并配独立 Vitest 单元测试。
- `UiStyleSpec` 直接兼容 `BrandSkinContract` 契约，经 `src/registry/skins.ts` 汇总注入组件工作台，实现品牌皮肤与流派皮肤统一换肤。
- 列表筛选通过 `nuqs` 同步至 URL（`?tone=...&scenario=...&mode=...`）；详情页左栏与顶部控制条同步 `?tpl=...&mode=...&r=...&tab=...`，保证切换流派时不重置当前选中的样板视图。

## 3. 关键决策
- 顶部下拉抽屉与侧栏流派列表统一挂载 `10×10px` 双色微色块（`DualSwatch`：左半画布底色 + 右半强调色），零文字噪音即可一眼辨识流派色温。
- 砍掉列表页冗余的独立「换肤对比（`?view=compare`）」视图，将列表聚焦为差异化缩略卡片墙，把同样板实时换肤体验集中收口在 `/styles/[slug]` 三栏工作台内完成。

## 4. 当前实现
- 已完成 `core/styles/`（含单测）、`registry/styles/` 下 10 个独立流派子目录、`features/styles/{specimens,styles-list,style-detail}/`（含 `StyleRightInspector` 与 `StyleGuardrailsTab`）与 `/[locale]/styles` 静态路由生成。

## 5. 验证方式
- 运行 `pnpm gate` 校验类型检查、代码规范、单测与生产构建；启动本机服务访问 `/zh/styles` 验证 10 套流派差异化卡片墙，进入 `/zh/styles/hairline-grid?tpl=landing&mode=dark&r=8` 切换左栏流派与四套样板验证状态保留、色板体检与护栏展示。

## 6. 待扩展项
