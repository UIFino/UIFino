# 首页与图鉴模板频道

- **模块定位**：实现站点首页、双端标杆设计图鉴（列表页与品牌 `DESIGN.md` 规范详情页）以及多页整站工程模板频道（列表页与模板详情预览）。
- **对应代码**：`src/features/home/`、`src/features/catalog/`、`src/features/templates/`、`src/app/[locale]/(site)/page.tsx`、`src/app/[locale]/(site)/catalog/`、`src/app/[locale]/(site)/templates/`
- **所属里程碑**：[M3](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：
  1. 首页：双栏竖纹首屏、四步复刻闭环交互轨、双端图鉴精选切换、四类组件分类速览、工具与 MCP 三栏导流带；
  2. 设计图鉴：平台类型（Web / App）与行业领域筛选、卡片明暗预览切换、品牌详情左树导航、实时标本预览 / 明暗同屏对比 / `DESIGN.md` 协议查看三标签切换、一键复制与 `.md` 文件下载、一键带入组件工作台；
  3. 整站模板：按场景分类与关键词筛选、双层路由叠卡预览、模板详情页及 CLI 复制、一键套用对应皮肤进入工作台。
- **不负责**：单组件三栏工作台内部源码适配与参数实验室滑块计算。

## 2. 结构与数据流
- 列表筛选状态（`kind`、`category`、`q`、`mode`）通过 `nuqs` 与 URL 查询参数双向同步，确保从顶部悬停大菜单带参点击（如筛选 `Mobile Apps` 或 `AI & LLM`）直达对应过滤视图。
- 图鉴详情页调用 `core/design-md` 实时编译标准协议文本，交由 `CodeViewer` 高亮渲染或触发浏览器 Blob 下载。

## 3. 关键决策
- 遵循界面文案最小必要信息守则，列表统计仅保留真实数量，剔除任何类似「持续扩充中」的版本备注噪点。

## 4. 当前实现
- 已完成 `features/home/`（分栏竖纹首屏、四步闭环演示轨、图鉴精选、组件分类速览、工具三栏导流带）、`features/catalog/`（URL 参数同步筛选列表、左树品牌详情、明暗色板同屏对比、Shiki 高亮 `DESIGN.md` 查看复制与下载）及 `features/templates/`（多页模板目录与详情页）。

## 5. 验证方式
- 生产构建通过；在浏览器逐一走查首页四步切换、图鉴按端/行业/搜索过滤、详情页 Light vs Dark 对比与下载 `.md`、模板分类筛选及跳转工作台链路。

## 6. 待扩展项
