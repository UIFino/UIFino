# 项目路线图（Roadmap）

> 当前进度：`M0` ~ `M6` 全部已完成，远程 `pnpm gate` 门禁全绿且真实浏览器多视口走查验收通过。

## 项目目标

基于 Next.js 15（App Router）、TypeScript 严格模式、Tailwind CSS v4 与 `next-intl` 双语路由，按支持百级组件与品牌资产扩展的六大区目录架构，1:1 高保真迁移现有 UIFino HTML 原型的全部视觉规范、全局交互与五大核心业务频道，并通过远程 `cicd mac` 全量门禁与真实浏览器多视口验收。

## 里程碑与架构分层的对应关系

- **`M0` 基础设施与公共组件底座**：对应 [架构设计 - 基础设施层与公共组件层](./架构设计.md#2-架构分层与单向依赖规则)，先把 CSS 变量令牌与通用 UI 组件立稳，杜绝后续业务页面硬编码。
- **`M1` 纯业务引擎与资产注册表**：对应 [架构设计 - 纯业务引擎层与资产注册表层](./架构设计.md#2-架构分层与单向依赖规则)，落实「一资产一目录」与零 React 依赖计算内核。
- **`M2` 路由装配与全局壳层**：对应 [架构设计 - 路由装配层与公共壳层](./架构设计.md#2-架构分层与单向依赖规则)，打通 `[locale]` 双语子路径与跨频道全局导航。
- **`M3` ~ `M5` 频道业务实现与端到端验收**：对应 [架构设计 - 频道业务层](./架构设计.md#2-架构分层与单向依赖规则)，分批交付首页及五大业务频道并完成远程门禁闭环。
