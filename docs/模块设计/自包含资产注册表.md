# 自包含资产注册表

- **模块定位**：按「一资产一独立文件夹」组织全站品牌图鉴、四类 UI 组件与动效、多页整站模板、参数实验室预设及 MCP 客户端配置，支撑后续百级资产平滑扩容。
- **对应代码**：`src/registry/catalog/`、`src/registry/components/`、`src/registry/templates/`、`src/registry/tools/`、`src/registry/mcp/`
- **所属里程碑**：[M1](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：分目录存储 12 套标杆品牌规范（8 个桌面网站 + 4 个移动应用）、16 个组件分类（横跨 Section / Block / Page / Motion 四大类）、4 套多页启动模板、背景与阴影预设、4 类 MCP 客户端配置，以及各自的微缩预览标本与聚合查询入口。
- **不负责**：筛选状态管理、URL 同步与外层频道框架布局。

## 2. 结构与数据流
- **品牌图鉴（`registry/catalog/`）**：按 `websites/<slug>/` 与 `apps/<slug>/` 拆分，单品牌目录自包含元数据、明暗色板与实现守则，由 `catalog/index.ts` 统一导出列表与按 `id` 查找函数。
- **组件库（`registry/components/`）**：按 `<assetType>/<category>/<component-slug>/` 三级目录拆分，分类级维护 `_category.ts`，单组件目录维护 `meta.ts` 与 `specimen.tsx` 实时预览组件。
- **整站模板（`registry/templates/`）**：一套模板一个独立目录，包含路由清单、绑定皮肤与叠层预览标本。

## 3. 关键决策
- 放弃单文件大数组存储方式，彻底改为按业务层级分目录的自包含资产单元，使后续新增几百个组件或并发派发多路开发任务时互不产生文件冲突。

## 4. 当前实现
- 已按独立文件夹注册 12 套标杆品牌图鉴（`websites/*` 8 套、`apps/*` 4 套）、16 个组件分类与 23 个具体组件元数据目录、4 套多页启动模板、背景与阴影预设、4 类 MCP 客户端配置及 5 频道悬停大菜单配置，并通过严格类型检查。

## 5. 验证方式
- 通过 TypeScript 严格模式校验所有资产元数据契约完整性，并结合 `core/search` 单测验证全量资产索引可正常遍历查询。

## 6. 待扩展项
- 支持从同目录下的 `.mdx` 或原始 `.tsx` 源码文件构建期自动提取元数据与预览树。
