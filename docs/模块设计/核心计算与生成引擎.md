# 核心计算与生成引擎

- **模块定位**：零 React 依赖的纯 TypeScript 业务内核，负责设计令牌合成、品牌与流派 `DESIGN.md` 协议编译、React + Tailwind 组件源码生成、四大参数工作室数学换算与全站检索匹配。
- **对应代码**：`src/core/tokens/`、`src/core/design-md/`、`src/core/styles/`、`src/core/codegen/`、`src/core/studios/`、`src/core/search/`
- **所属里程碑**：[M1](../roadmap.md#里程碑总览)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：
  1. `tokens/`：根据圆角档位、排版密度、品牌皮肤与明暗模式计算最终色值、间距与 Tailwind 类名，并导出标准 `tokens.css`；
  2. `design-md/`：编译符合 `uifino/design-md@1.0` 规范的 YAML Frontmatter 与结构化正文；
  3. `codegen/`：按虚拟文件树与 `adapters/{react,vue,svelte,solid}` 生成注入实时令牌后的源码；
  4. `studios/`：计算网格、点阵、极光、颗粒噪点背景及多层阴影的内联样式与 CSS / Tailwind 代码；
  5. `search/`：提供 `⌘K` 全站资产搜索索引过滤与 MCP 协议多维匹配载荷生成。
- **不负责**：界面渲染、浏览器剪贴板写入与路由跳转。

## 2. 结构与数据流
- 每个领域作为独立子包拆分 `types.ts`、核心计算模块、`index.ts` 门面与 `__tests__/*.test.ts` 单元测试。
- 输入统一为纯数据对象，输出为确定性结构化结果或格式化源码字符串，可同时在服务端、客户端与未来的独立 MCP Server 进程中直接复用。

## 3. 关键决策
- 多框架代码生成采用适配器子目录架构（`adapters/react`、`adapters/vue`、`adapters/svelte`、`adapters/solid`），后续扩充新框架只需新增独立适配器目录。
- 所有数值参数（透明度、模糊度、网格间距、圆角）均在引擎入口做边界夹紧（Clamp），防止非法 URL 参数导致生成异常 CSS。

## 4. 当前实现
- 已完成 `tokens/`、`design-md/`、`styles/`（流派协议编译与表面物理参数计算）、`codegen/`（精简为标准单栈 React + Tailwind `.tsx`、`tokens.css` 与 `DESIGN.md` 输出）、`studios/{background,shadow,colors,typography}/` 与 `search/` 六大子包及全部 6 组 Vitest 单元测试。

## 5. 验证方式
- 在 `cicd mac` 执行 `pnpm test`（Vitest），验证令牌计算、品牌与流派协议编译、组件源码输出、背景/阴影/色阶对比度/字号阶梯换算与全局检索断言全部通过。

## 6. 待扩展项
