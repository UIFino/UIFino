# 多语言与全局导航壳层

- **模块定位**：管理 `/zh/...` 与 `/en/...` 双语子路径路由、按频道分片的翻译词条、Zustand 全局预设状态，以及顶部公告条、5 频道悬停大菜单、`⌘K` 全局搜索、令牌预设浮层与建筑网格页脚。
- **对应代码**：`src/middleware.ts`、`src/i18n/`、`src/stores/`、`src/app/icon.svg`、`src/app/apple-icon.tsx`、`src/app/[locale]/`、`src/components/shell/`、`src/registry/navigation/mega-menus.ts`
- **所属里程碑**：[M2](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：多语言路径识别与切换（保留当前子路径参数）、分频道 JSON 词条按需拼装、吸顶纯文字导航栏（第五频道命名为「接入到AI / Connect AI」）与 5 频道通栏多列纯文字抽屉菜单（配全屏压暗毛玻璃遮罩）、`⌘K / Ctrl+K` 键盘导航命令框、右上角全局工作台预设浮层、明暗主题切换与底部四栏导航。
- **不负责**：各频道主内容区的具体筛选与舞台渲染。

## 2. 结构与数据流
- `src/middleware.ts` 基于 `next-intl/middleware` 拦截请求，将无前缀路径引导至默认语言 `/zh`，并支持切换至 `/en` 同构路径。
- `src/i18n/messages/{zh,en}/` 拆分为 `common`、`home`、`catalog`、`library`、`templates`、`tools`、`mcp` 七个独立 JSON 文件，由 `request.ts` 在服务端合并注入。
- `SiteHeader` 采用零箭头、零角标的纯文字频道链接，底部高亮指示条通过 `openMenu ?? activeChannel` 单一激活源加两侧内缩（`inset-x-3`）绘制，悬停打开任意抽屉菜单时仅高亮当前悬停项，关闭抽屉后恢复当前路由所属频道高亮；右侧工具区仅保留 `⌘K` 全局搜索、令牌预设、中英切换与明暗主题切换四项真实功能控件。
- `MegaMenuViewport` 采用通栏多列纯文字抽屉布局（第 1 列 `21px` 宏观维度主入口 + 右侧 `13.5px` 多列细分索引，中文模式统一使用纯中文命名、英文模式统一使用纯英文命名），并在下方挂载全屏半透明模糊遮罩隔绝页面背景干扰。其中「设计图鉴」抽屉按「探索设计图鉴（浏览全部 / 桌面网站 / 移动应用）+ 按行业领域（6 大领域）+ 网站标杆 + 应用标杆」四列清晰分层。
- `CmdkPalette` 监听全局 `⌘K / Ctrl+K`，调用 `core/search` 实时过滤全站资产并支持键盘方向键与回车跳转。

## 3. 关键决策
- 词条按业务频道拆成独立小文件，杜绝多页面并行修改文案时的合并冲突。
- 主站路由放入 `(site)` 分组统一挂载顶底壳层，独立预览画布放入 `(canvas)` 分组保持零壳层纯净渲染。

## 4. 当前实现
- 已完成 `src/middleware.ts`、`src/i18n/{routing,navigation,request}.ts` 与 `zh`/`en` 各 7 个频道分片 JSON 词条文件。

## 5. 验证方式
