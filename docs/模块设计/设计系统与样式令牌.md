# 设计系统与样式令牌

- **模块定位**：提供全站统一的明暗双主题 CSS 变量、字体本地化托管、原子级交互原语组件与跨频道组合模式组件。
- **对应代码**：`src/styles/`、`src/lib/fonts.ts`、`src/lib/cn.ts`、`src/lib/shiki.ts`、`src/hooks/`、`src/components/primitives/`、`src/components/patterns/`
- **所属里程碑**：[M0](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：维护暗色炭黑与亮色暖纸张两套语义 CSS 变量、Tailwind v4 `@theme` 工具类映射、4 款 Google 字体自托管、直角细边框按钮/徽章/分段器/输入框/滑块等原子组件，以及统一频道横幅、Shiki 语法高亮代码框、空状态/错误态等复用模式块。
- **不负责**：具体频道的筛选状态、资产目录数据查询与多语言路由分发。

## 2. 结构与数据流
- `src/styles/tokens/` 分文件定义 `dark.css`、`light.css`、`typography.css`、`layout.css`，由 `src/styles/globals.css` 统一聚合。
- `next-themes` 在根节点写入 `data-theme="dark" | "light"`，CSS 变量即时切换，组件层仅消费语义变量名。
- `CodeViewer` 接收源码字符串与目标语言标识，经 `src/lib/shiki.ts` 渲染双主题语法高亮 HTML，并联动剪贴板 Hook 触发复制提示。

## 3. 关键决策
- 样式文件按明暗主题、排版、表面纹理分片存放，避免单一全局 CSS 膨胀至上千行。
- 所有外框架组件保持 `0px` 直角与 `1px` 结构线，工作台预览区内部单独消费动态圆角令牌，互不串扰。

## 4. 当前实现
- 已完成 `package.json`、`pnpm-workspace.yaml`、`tsconfig.json`（严格模式）、`next.config.ts`、`eslint.config.mjs` 与 `vitest.config.ts` 配置。
- 已按 `tokens/{dark,light,typography,layout}.css` + `utilities/surfaces.css` + `globals.css` 分层落地双主题令牌，完成 4 款 Google 字体本地化封装与 Shiki 高亮工具封装。
- 已完成 `primitives/`（Button、Badge、SegmentedControl、SearchInput、RangeSlider、NativeSelect、Popover、Dialog、Tabs）与 `patterns/`（PageBanner、CodeViewer、FilterToolbar、ViewportFrame、TokenSwatchGrid、EmptyState）组件实现，并在 `cicd mac` 通过 `pnpm typecheck`。

## 5. 验证方式
- 运行远程 `pnpm typecheck` 与 `pnpm lint` 零报错；在浏览器切换 Dark / Light 主题验证色板无闪烁且对比度达标。
