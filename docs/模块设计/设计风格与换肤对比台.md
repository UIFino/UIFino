# 设计风格与换肤对比台

- **模块定位**：提炼 10 套通用 UI 设计流派的明暗色板、圆角档位、边框阴影特征与设计护栏，提供流派画廊、同界面实时换肤对比台与流派 `DESIGN.md` 详情页，并与组件预览皮肤系统无缝互通。
- **对应代码**：`src/core/styles/`、`src/registry/styles/`、`src/features/styles/`、`src/app/[locale]/(site)/styles/`、`src/i18n/messages/{zh,en}/styles.json`
- **所属里程碑**：[M6](../roadmap.md#里程碑总览)
- **前端设计规范**：[前端设计](../前端设计.md)
- **当前状态**：已完成
- **最近更新时间**：2026-11-27

## 1. 职责与边界
- **负责**：
  1. 维护现代克制系（细线网格、极简黑白、瑞士排版、清爽商务、杂志衬线）与质感先锋系（毛玻璃、便当格、新粗野、微浮雕、复古终端）共 10 套流派资产；
  2. `/styles` 频道页：支持画廊网格与「换肤对比台」双视图，按深浅色系、四大适用场景与关键词过滤；在换肤对比台内将同一套标准控制台界面（顶栏、三栏指标卡、输入框与按钮、动态列表）按所选流派实时切换圆角、边框粗细、硬偏移阴影、毛玻璃模糊或扫描线质感；
  3. `/styles/[slug]` 详情页：展示实时样板预览、深浅色板对照、表面特征与实现护栏、Shiki 高亮 `DESIGN.md` 查看/复制/下载，以及一键套用至组件预览工作台。
- **不负责**：具体行业品牌的专属规范拆解（归属 `catalog` 频道）。

## 2. 结构与数据流
- `src/core/styles/` 提供纯函数协议编译器 `compileStyleDesignMd` 与表面物理参数换算器 `resolveStylePlaygroundPhysics`，无 React 依赖并配独立 Vitest 单元测试。
- `UiStyleSpec` 直接兼容 `BrandSkinContract` 契约，经 `src/registry/skins.ts` 汇总注入组件工作台，实现品牌皮肤与流派皮肤统一换肤。
- 筛选与当前选中流派通过 `nuqs` 同步至 URL（`?view=compare&tone=...&scenario=...&style=...`），与顶部四列抽屉菜单直达链接完全打通。

## 3. 关键决策
- 顶部下拉抽屉与侧栏流派列表统一挂载 `10×10px` 双色微色块（`DualSwatch`：左半画布底色 + 右半强调色），零文字噪音即可一眼辨识流派色温。
- 换肤对比台内置「默认色调 / Dark / Light」三态切换，默认展示该流派最具代表性的原生明暗基调，同时允许强制切到深色或浅色横向比对。

## 4. 当前实现
- 已完成 `core/styles/`（含单测）、`registry/styles/` 下 10 个独立流派子目录、`features/styles/{specimens,styles-list,style-detail}/` 与 `/[locale]/styles` 静态路由生成。

## 5. 验证方式
- 运行 `pnpm test` 校验协议编译与物理参数计算；在浏览器访问 `/zh/styles?view=compare` 逐一切换 10 种流派验证圆角、粗边框硬投影、毛玻璃与终端扫描线实时生效，并测试跳入详情页与套用至组件工作台。

## 6. 待扩展项
- 后续随友商调研继续在 `src/registry/styles/<slug>/` 横向扩充更多细分视觉流派。
